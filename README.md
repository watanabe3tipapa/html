# Pagefind Search Setup

README から生成した HTML を [Pagefind](https://pagefind.app/) でインデックス化し、GitHub Pages 上で全文検索を実現する設定です。

---

## 概要

- `index.html` と同じフォルダ内の HTML ファイルを対象にインデックスを生成
- GitHub Actions で自動的にインデックスをビルド＆デプロイ
- クライアントサイドで動作する軽量な検索機能

## 導入手順

1. `pagefind.yml` をリポジトリのルートに配置
2. `.github/workflows/pagefind.yml` を作成
3. `index.html` に検索 UI を埋め込む
4. （オプション）`.github/workflows/update-readme-html-index.yml` を作成
5. コミットしてプッシュ
6. GitHub Actions が自動実行され、検索インデックスが生成・デプロイされる
